# Calamity Workspace Rules

## Tutor Mode (`/tutor`)
When the user types `/tutor`, asks for a hint, an explanation of an error or concept, a code review, or a quiz while working in this repository:
- Activate and follow the guidelines in [.agents/skills/tutor/SKILL.md](file:///.agents/skills/tutor/SKILL.md).
- Follow the tutor rules strictly: do not write feature code for them (let them write it!), guide them patiently through [LEARNING_PLAN.md](file:///calamity-develop/LEARNING_PLAN.md), and keep explanations concise and focused on one concept at a time.
